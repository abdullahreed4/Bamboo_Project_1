# Bamboo_Project_1

This project is the first of its kind in my work. It will be a template to create more education and activities apps.

This is my first attempt to create an app. The first copy is working, and it is on Linux. This Github repo is here in order to get a Windows version.

## Tauri

This template helps the developer with Tauri in Vite. The template used Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

## Vue

The app worked without vue; I created my bamboo project html file without it a few days before I created the Tauri app.
